# Sarika Portfolio Theme

A custom WordPress portfolio theme built from scratch for a WordPress Developer with 3+ years of experience.

## Live Preview
> Hosted locally at `http://localhost/myportfolio`

## Features
- Fully custom WordPress theme — no page builders
- Responsive dark design with purple accent
- Hero section with CTA buttons
- About section with stats
- Skills section with categorized skill tags
- Projects section with GitHub links
- Contact section with email, GitHub and LinkedIn
- Smooth scroll and fade-in animations
- Mobile-friendly hamburger navigation
- Active nav link highlight on scroll
- WooCommerce support

## Tech Stack
- PHP
- HTML5
- CSS3 (Flexbox, CSS Variables, Animations)
- JavaScript (Vanilla JS, DOM Events)
- WordPress Template Hierarchy

## Theme Structure
```
sarika-portfolio/
├── style.css           # Theme registration
├── functions.php       # Enqueue scripts, theme support, menus
├── index.php           # Fallback template
├── front-page.php      # Homepage template
├── header.php          # Site header and navigation
├── footer.php          # Site footer
├── page.php            # Single page template
├── woocommerce.php     # WooCommerce template
├── main.css            # All custom styles
└── main.js             # JavaScript interactions
```

## Installation
1. Download or clone this repository
2. Upload the `sarika-portfolio` folder to `/wp-content/themes/`
3. Go to **Appearance → Themes** in WordPress admin
4. Activate **Sarika Portfolio**
5. Go to **Settings → Reading** → set a static front page
6. Visit your site homepage
